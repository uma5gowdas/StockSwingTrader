================================================================================
                        TROUBLESHOOTING
================================================================================

Q: "I don't see Robinhood in MCP tools"
A: Restart Kiro with Cmd+Shift+P → Developer: Reload Window

Q: "Authentication failed"
A: Clear browser cookies, try again. Check Robinhood account is active.

Q: "Order didn't go through"
A: Check buying power, market hours (9:30 AM - 4:00 PM EST), funds.

Q: "Token expired"
A: Tokens auto-refresh. If stuck, ask Kiro again - it will re-auth.

Q: "How is this different from OAuth setup in shell script?"
A: This uses official Robinhood MCP. Shell script needs OAuth registration
   (which Robinhood doesn't allow for third-party apps). MCP is official.
