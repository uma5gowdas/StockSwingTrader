TROUBLESHOOTING
================================================================================

Q: "Error: Missing Alpaca API credentials"
A: Make sure config.sh is sourced: source config.sh

Q: "Error: Alpaca API connection failed"
A: Check internet connection and verify API keys in config.sh

Q: "jq error" when getting account
A: This is usually formatting issue, not critical. Install jq: brew install jq

Q: "Insufficient buying power"
A: Check account balance: ./StockSwingTrader_Agent.sh --check-account
   You have $100,000 starting capital

Q: Can't see positions after placing trade
A: Market must be open. Paper trades fill at market price when market is open.

For more help:
- See TROUBLESHOOTING section in API_SETUP_GUIDE.md
- Check logs: cat logs/alpaca.log
- Enable debug: source config.sh && export ALPACA_DEBUG=true
