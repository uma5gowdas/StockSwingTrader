================================================================================
                        SUPPORT & TROUBLESHOOTING
================================================================================

Missing Credentials Error?
  → source config.sh before running agent
  → or ./RUN_TRADING.sh wrapper (auto-loads config)

No Positions Showing After Order?
  → Market may be closed; orders fill at 9:30 AM EST
  → Check: ./CHECK_ORDERS.sh (shows ACCEPTED/FILLED status)
  → Wait 2 minutes and retry

Strategy Not Triggering?
  → Enable debug mode: --debug --symbols AAPL
  → Shows all indicator calculations and entry condition checks
  → Review: DESIGN_v6.1.md for entry condition details

Trade Journal Not Updating?
  → Check permissions: ls -la logs/
  → Verify logs/ directory writable
  → Check agent.log for errors

API Connection Issues?
  → Test credentials: ./StockSwingTrader_Agent.sh --check-account
  → Verify API key/secret in config.sh
  → Check internet connectivity
