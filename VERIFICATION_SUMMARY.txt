RECOMMENDATIONS FOR USERS
================================================================================

Getting Started:
  1. Sign up at https://alpaca.markets
  2. Generate API keys at https://app.alpaca.markets/paper/settings/api
  3. Export credentials in shell:
     export ALPACA_API_KEY="your_key_here"
     export ALPACA_SECRET_KEY="your_secret_here"
  4. Test with: ./StockSwingTrader_Agent.sh --alpaca --check-account

Analysis + Trading:
  ./StockSwingTrader_Agent.sh --alpaca --symbols AAPL,MSFT,GOOGL

Risk Management:
  - Review ALPACA_MAX_POSITION_SIZE in config.template.sh
  - Keep ALPACA_AUTO_TRADE=false for manual confirmation
  - Monitor logs in logs/alpaca.log

Troubleshooting:
  - Check credentials: echo $ALPACA_API_KEY
  - View logs: tail -f logs/alpaca.log
  - Test connection: ./StockSwingTrader_Agent.sh --alpaca --alpaca-status
  - Run without Alpaca if issues: ./StockSwingTrader_Agent.sh --symbols AAPL
