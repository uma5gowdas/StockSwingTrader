================================================================================
                        ROBINHOOD CLI COMMANDS
================================================================================

./robinhood-cli auth                  # One-time OAuth setup
./robinhood-cli account               # Show account & balance
./robinhood-cli positions             # List positions
./robinhood-cli quote SYMBOL          # Get price quote
./robinhood-cli buy SYMBOL QTY        # Market order (buy)
./robinhood-cli buy SYMBOL QTY PRICE  # Limit order (buy)
./robinhood-cli sell SYMBOL QTY       # Market order (sell)
./robinhood-cli sell SYMBOL QTY PRICE # Limit order (sell)

Example:
  ./robinhood-cli buy AAPL 10         # Buy 10 AAPL at market
  ./robinhood-cli buy MSFT 5 350      # Buy 5 MSFT at $350 limit
  ./robinhood-cli sell GOOGL 3        # Sell 3 GOOGL at market

================================================================================
                        MULTI-BROKER SETUP
================================================================================

Run both Alpaca and Robinhood simultaneously:

Terminal 1 (Alpaca):
  source config.sh
  ./StockSwingTrader_Agent.sh --monitor-positions &

Terminal 2 (Robinhood):
  ./robinhood-cli account
  ./robinhood-cli buy AAPL 10

Both trades logged to: logs/trades.json

View unified journal:
  cat logs/trades.json | jq '.'

Filter by broker:
  cat logs/trades.json | jq '.[] | select(.broker == "robinhood")'

================================================================================
                        TROUBLESHOOTING
================================================================================

Issue: "command not found: jq"
Fix: brew install jq (macOS) or apt-get install jq (Linux)

Issue: "Permission denied" on robinhood-cli
Fix: chmod +x robinhood-cli

Issue: Robinhood auth fails
Fix: rm ~/.robinhood_mcp_tokens.json && ./robinhood-cli auth

Issue: Alpaca connection fails
Fix: source config.sh && echo $APCA_API_KEY_ID

Issue: Scripts not found
Fix: Make sure you're in the StockSwingTrader directory

See TROUBLESHOOTING.md for more help.
