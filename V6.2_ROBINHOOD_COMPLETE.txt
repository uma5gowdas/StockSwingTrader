================================================================================
                         TROUBLESHOOTING
================================================================================

Issue: "Robinhood OAuth failed"
  → Check internet connection
  → Verify browser can access https://api.robinhood.com
  → Try --setup-robinhood again

Issue: "Tokens expired"
  → Tokens auto-refresh automatically
  → If manual refresh needed: rm ~/.robinhood_tokens.json && --setup-robinhood

Issue: "Permission denied for Robinhood account"
  → Ensure Robinhood account has standard/margin enabled
  → Not all Robinhood account types support API access

Issue: "No positions after trade on Robinhood"
  → Market may be closed; orders fill at 9:30 AM EST
  → Check: ./StockSwingTrader_Agent.sh --broker robinhood --show-journal
  → Wait 2 minutes if using paper/sandbox

Issue: Can't switch between brokers
  → Each broker uses different credentials/tokens
  → Alpaca: API key/secret in config.sh
  → Robinhood: OAuth tokens in ~/.robinhood_tokens.json
  → Both can be set up independently
